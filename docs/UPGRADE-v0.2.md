# 海边照片片段 · 视觉升级试验 v0.2

在既有chat-animation-studio2内增加SeasideUpgrade composition，保留Seaside及v0.1文件。新片54秒、2560×1440、30fps、无声。

技术借鉴用户文件04的连续路径、06的等点数形状插值、07的大画布虚拟镜头。未采用该文件的配色、金属发光、粒子、贴纸、回弹、美术故事或音频要求。

原创改动：全幅海景进入；6000×3000世界画布内四次有目的的构图切换；照片固定，关系端点与照片绑定；摄影观察框以64个对应点平滑扩展为宽幅海景观察范围。只改变观察范围，不扭曲照片。长句阅读期间相机严格停止。

参考依据仍为既有05的渐进关系与对比、02的局部/整体空间联系、10的分层文字。坐标、配色、镜头、观察框与排时为本项目原创，不称参考实测值。

原文七段逐字验证。开发命令：npm run frames:upgrade；npm run render:upgrade；python scripts/verify-upgrade.py。输出位于output/v0.2，旧版输出不覆盖。
