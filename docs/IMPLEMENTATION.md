# 方案二实现记录 · 0.1.0

范围只限方案二，未扩展到其他分镜。

## 参考依据

- 05《月老的算法》35.830—38.663秒：固定对象、渐进路径、弱化无关对象。
- 05，86.000—88.833秒：同屏比较。
- 02《交通悖论》36.510—39.343秒：拉远展示整体。
- 02，87.620—90.453秒：保持同一模型，只改变当前解释条件。
- 10《得不到》67.360—70.193秒：按语义分层建立文字。

## 本项目原创设计

暖纸色背景、自然海景、石墨文字、赭色摄影分支、青绿色大海分支；照片作为同一锚点，先解释一支再解释另一支，最后恢复两支同等清晰。不是参考片测得参数或既有模板。

工程帧率30，片长48秒：

|段落|时间|主要事件|
|---|---|---|
|B1|0—3.7秒|照片与原文引入|
|B2|4.2—18.85秒|“你可以说”与完整开场句分组建立；阅读时画面固定|
|交接|19—20.3秒|长句读完后照片整体收至共同起点|
|B3|20.6—27秒|完整“如果喜欢拍照”原句与摄影路径|
|B4|27.6—37.6秒|完整“如果喜欢大海”原句；旅行、风景、环境原因依次展开|
|B5|37.65—48秒|先拉远停稳，再“你发现没有”，最后完整总结|

正文、图形标签均来源于原文；标签重复用于图解，不替代完整句。字幕文件为原文辅助交付，不是配音。

## 画面检查后调整

摄影标签上移20px，大海偏好标签上移37px；环境说明小幅上移，底部长句上移并调整行距，最终总结上移30px。用于消除文字包围框与曲线冲突、满足安全区，不修改文案或叙事。

## 技术选择

Remotion 4.0.536锁定，React 19.2.0，本地Chromium。官方CLI模板因DNS失败未能克隆，手动建立最小工程。官方四项Skills安装在本工程 `.agents/skills/`，没有引用旧工程。

SVG开放路径由统一时间轴和De Casteljau子曲线驱动，不使用Flubber：本段不存在需要封闭形状变形的语义条件。原文、尺寸、时间与样式分离，可独立编辑。

本地字体装载使用delayRender/continueRender等待，避免字体替换造成布局变化。字体以WOFF子集加载，完整TTC附在素材目录供编辑扩展。
