## 内容与工程

- 用户图片的四类共23个分项都有对应表达，详见 assets/content-map.json。
- 这套分类是观察框架，不是经过验证的心理分级；图形不代表好感、价值或成功率。
- 没有新增 npm 依赖。复用固定版本 Remotion/React；新下载并实际使用官方 Kokoro 模型。源工程含可直接渲染的音轨，不需模型即可重新渲染。
- Python分析/声音重制脚本需 NumPy/SciPy/Pillow/fontTools；语音重制另需 sherpa-onnx 与官方模型。日常视觉修改与重渲染不依赖这些 Python 步骤。
