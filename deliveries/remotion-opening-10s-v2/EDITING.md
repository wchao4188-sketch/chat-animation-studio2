# 新世界｜10秒样片 v2

本轮独立合成 `NewWorldOpeningV2`，入口 `src/v2/index.tsx`。v1 的入口、源码、MP4、工程ZIP和验收记录保持原样。只制作10秒，不扩展整片。

## 运行与编辑

依赖沿用锁文件，不新增依赖：Remotion / CLI / media / fonts 4.0.536，React 19.2.4，TypeScript 5.9.3。

```bash
npm ci
npm run typecheck
npx remotion studio src/v2/index.tsx --port=3102 --browser-executable=/usr/bin/chromium
bash scripts/render-v2.sh
```

渲染输出 `output/v2/NewWorld-Remotion-10s-v2.mp4`，2560×1440，30fps，300帧，H.264/AAC。浏览器路径按本机实际安装修改；不要运行旧的 `npm run render` 来渲染v2。源包不包含node_modules，字体和实际音乐均在public内。

## 这轮动作链

- 0–2.710秒：保留暖米色、深色手机与原排版；手机轻微靠近并转向，女性主体身份始终一致。
- 2.710–3.768秒：屏幕第一行压缩，橙色接点从真实屏幕行延伸至机框。
- 3.768–5.903秒：中心手机退出近景，左侧手机从画外进入；曲线从中心接点持续生长至左侧接点。
- 5.200–5.650秒：手机已让出空间后，上方说明文字才揭示，避免遮挡。
- 5.903秒：第一根线完成，屏幕保留男生01；新行展开，右侧手机进入。
- 6.431–6.961秒：第二根线从第二行接点长至右侧手机；完成后屏幕保留男生02。
- 7.240秒后：手机、连线、地面关系停止运动；7.780–8.300秒揭示原有提问，之后整幅画面停留至结尾。

没有新增问答、好感评分或心理结论。原题目与开头情境文字保持。矢量路径、屏幕局部遮罩与固定字体布局参与连续变化；没有静态截图拼接。每根线上只有一个临时生长前端标记，完成后消失。

## 坐标与确定性

`geometry.ts` 统一定义手机位姿、CSS透视投影、接点与Bezier控制点。画面上的线与屏幕内端点使用同一投影坐标；路径前端使用弧长反求，避免把Bezier参数误当作路径长度。动画仅依赖帧号，没有随机数、计时器或实时物理模拟。

`OpeningV2.tsx` 每帧用浏览器实际DOM矩形测量手机接点与世界接点的误差，并用SVG的实际getPointAtLength测量路径前端。误差超过0.25像素会主动终止渲染。这个检查不驱动画面。

## 音乐

沿用v1 `public/music-opening.wav` 原文件与时间轴，不添加配音或音效。原素材分析的75.17/113.46 BPM候选接近，不能据此断言唯一BPM或小节重拍。动作参考实际测得的0.845、2.710、3.768、4.317、5.903、6.701、6.961、7.779秒能量起音；阅读停留优先，不逐拍切画面。

验收见 `output/v2/验收记录-v2.md`、`quality.json`、`review/`。音乐同步和响度做了实际解码分析；没有将自动音频检测写成已人工试听。
