- 三维工具不可用时任务阻塞，没有转成二维；备用渲染入口遇到未实现的props参数时拒绝执行，没有丢弃参数继续。

## 4. 测试中暴露并处理的问题

1. **中间音轨拉长画面拼接。** 初轮渲染器附带静音AAC，导致封装超过10秒约0.056秒。已改为中间镜头只输出视频，最终统一封装精确10秒混音；原先失败结果另存，不当作通过。
2. **上游审核的语义字段超出检测能力。** 音量阈值不能证明“有旁白”或“混音可懂”；简单抽帧不能证明“文字可读”。原报告保留，规范化报告将这些内容标为未由指标验证，最终画面另行实际检查。
3. **预检未检测时间轴空隙。** 已实测并补充帧级连续性检查，没有把上游成功返回直接当成时间轴完整。
4. **转场编码控制有限。** crossfade技术测试可运行，但末段编码质量参数传递有限；本次不把它用作主片的额外压缩步骤。
5. **运行时可用性有缓存影响。** HyperFrames注册表检测先后有差异；CLI 0.8.184实际运行成功，但没有完成其成片渲染验证，因此没有把它列为本片已验证路径。

## 5. PDF知识蒸馏与本期导演决策

该PDF共7页，内容是课程作者的交流观点和个人经历，不能直接称为研究证据。保留的主题包括：倾听和适度停顿、适当分享、从回应里的具体信息继续交流、用开放问题了解情境。

本次选第6—7页旅行例子，提炼为“商业化”这个词可能包含对旅行氛围的感受或期待，但仍需询问验证。前5秒展示原句并抽出关键词；后5秒从同一锚点生长“感受/期待”两条路径，连接到原创问题：“你原本期待的旅行，是什么样的？”

原文中的推广内容、群体和性别概括、把提问等同于人格强弱的判断、从个人轶事推断普遍吸引力的说法没有进入成片。新增对话标为原创演绎。屏幕文案不使用效果承诺，也不把“无限话题”的资料标题变成视频结论。

## 7. 更新后的完整工作流

`资料入库与来源哈希 → 按页蒸馏并标记证据层级 → 原创文案与承诺表达检查 → AI导演形成镜头需求 → 统一适配层按能力与实测状态选工具 → Open Montage素材/预检/渲染入口 → 按需Remotion或其他视觉工具 → Open Montage剪辑与混音 → 保留视频流的最终封装 → 自动技术检查＋实际画面审阅 → 版本化交付及下载校验`。

详见`Workflow.md`，其中列出每阶段输入输出、调用方式、缓存与回退边界。当前Codex承担语义与导演判断，代码执行结构化任务；本次没有把“工具接入”夸大为不需要审阅的全自动创作服务。
