# 第二遍｜新世界原创竖屏短片

46秒，1080×1920，9:16，30fps，1380帧。人物对话与环境叙事，没有说理旁白。音乐严格使用用户指定的`mmexport1792300994359.mp3`的真实音轨前46秒；原上传实为含AAC的MP4容器。

## 看故事

咖啡店里，两杯咖啡引来一句“先别问我了”。停下问话后，男生看见桌上的通话记录与折皱面试稿。他问起刚才的电话，随后挪动椅子，陪她重新练习自我介绍。结尾停在她重新开口，没有许诺面试成功，也没有爱情结论。

## 预览与渲染

```bash
npm ci
npm run typecheck
npm run studio
npm run render
```

默认浏览器路径`/usr/bin/chromium`，其他电脑修改`scripts/render.sh`和studio脚本为本机Chrome/Chromium路径。主合成`SecondTake`，入口`src/index.tsx`。无需Python或语音模型也能用包内现成音轨重新渲染。

## 可编辑内容

- `src/Film.tsx`：人物、口型、眨眼、视线、姿态、杯子/托盘、电话、面试稿、椅子、雨窗、木桌、光影、镜头与字幕。原创SVG，非截图拼接。
- `src/dialogue.json`：9句对白、人物身份、起止时间。`mouths.json`是从各句真实波形计算的逐帧口型包络。
- `public/audio/voice-*.wav`：逐句可替换配音。`music-selected.wav`是用户音乐原音轨的46秒截取；`ambience-foley.wav`为本工程制作的雨声、杯子、纸张及椅脚声。
- `final-mix.m4a`：实际用于成片的混音母带；`final-mix.wav`为无损版本。
- `scripts/sound.py`：混音、逐句自动音乐闪避、声效位置与音轨结尾淡出。使用2.58–2.74秒和4.85–5.08秒平滑增益曲线，避免情绪音乐变化产生硬切。
- `scripts/music.py`：实际音乐频谱起音/BPM候选分析，原始音乐源路径需按电脑调整；现成音乐截取已包含在public。
- `scripts/voice.py`：使用已有Melo VITS模型生成对白，需sherpa-onnx和模型；模型不随包重复附带。可直接编辑已提供的逐句WAV，不必重新合成。`asr.py`为可选机器核查，需要Paraformer模型。
- `scripts/quality.py`：实际成片解码、画面采样、响度和字体/时间轴检查。

## 实际依赖

无新增npm依赖：沿用Remotion/CLI/fonts/media 4.0.536、React/React DOM19.2.4、TypeScript5.9.3及现有锁文件。Python制作阶段复用NumPy、SciPy、Pillow、fontTools、既有sherpa-onnx1.12.35；FFmpeg用于音频提取、移调、混音、合成及验收。没有新增粒子/WebGL/三维插件。

## 音乐与节奏

分析输出`output/music-analysis.json`保留源SHA-256、能量曲线、起音点与帧号。约112.35/74.90 BPM为自相关候选，不能据此保证唯一速度或小节重拍。桌面转场第320帧、提出重来第767帧、对方抬头/发问第911帧、重新开口第1166帧，对应实测起音点。对白速度按人物交流安排，不靠强行压缩口播追拍。

每个镜头约2–5秒，以桌面特写、视线和椅子挪动推动关系变化。只为重要动作设置声效；原音乐在对白下自动降低，雨声作为实际场景声。

## 参考与许可

复核了已提供15条案例总览与飞机幸存者偏差连续抽帧，参考“主体持续承载信息→局部揭示→转折→停留”的方法，没有复制题材或使用参考画面。暖色纸感、低饱和橄榄绿与陶土色用于雨天咖啡店的原创人物故事。

人物和场景为本工程原创SVG。用户音乐按本次制作授权使用，不主张其版权。字体Noto CJK，许可随public/fonts提供；本地语音模型许可见licenses。

当前工具不支持人工听觉输入；声音完成机器检测与浏览器解码播放测试，未声称人工完整试听。检查范围与具体结果见`output/验收记录.md`。
