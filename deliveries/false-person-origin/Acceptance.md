# 《伪人起源》实际制作与检查

## 成片

1920×1080、16:9、30fps、2160帧、72.000000秒；H.264 / yuv420p、AAC / 48kHz / 双声道。无新增配音。
38,666,732字节；SHA-256 `b04d4f1ff42ffbdd5f45ed9eb3eb5befff8325a81591fb8ae9b0a196e040fe52`。

## 创作与素材

根据用户上一张年龄经验模型图，创作为关于误判的视觉寓言。标题“伪人起源”按本轮要求；“伪人”是脑中未经验证的想象，不是把他人称为怪物。年龄比例注明经验设定、非人口统计；周末待在家的聊天明确标注虚构。

本轮AI生成透明石膏雕塑PNG，SHA-256 `e4c6a9427982c8eef63f32c5d5bae0124461138b1431a80437a97fe40c2cb522`。不是人像实拍，也不是Blender/Three.js三维网格。使用24个原图切片的2.5D空间动画、连续遮挡、翻面与档案纸构图。旧视频不是视觉模板，旧工程没有覆盖。

## 实际修改

确定主视觉后，检查了开场、片名、档案、双维度纸条、虚构聊天、修正过程、翻面、结尾的实际渲染帧。将五步修正与五组切片重新对齐绑定；问题纸条提前完成翻面，保留阅读时间；统一退出方向，避免纸条横穿结尾文字。

首版全片检查发现45秒情境纸条硬切消失，随后改为连续滑出、从下方揭示新文字；同时使模拟地面阴影随面具拆解减弱，避免面具离场后残留孤立阴影。以上修改后重新渲染整片。

第二轮密集转场检查又发现47.7秒附近文字向右退出时受到浏览器自动收缩影响而重排。随后为文字和页眉固定版心宽度，独立重渲第1398—1439帧，按帧裁切合入完整2160帧影片；原AAC音轨直接复制，没有重混或替换。拼接后统一为固定30fps时间戳，并从原成片恢复完整72秒AAC音轨。再次对最终MP4完整解码、全长浏览器播放和实际转场帧检查。

音乐制作中发现原始采样率不能直接假定48kHz，因此先显式重采样再变速。实际处理后音乐文件时长已读取确认72秒，没有用补静音冒充等时素材。

- 第1875帧重复渲染PNG逐字节相同：True。

## 声音

处理后音乐主BPM候选85.227，未人工确认小节重拍。72秒音乐来自用户素材38—92秒的0.75倍速处理。音效为本地合成，含与实际变换时间一致的连续摩擦纹理；没有新旁白。

混音AAC技术测量约 −16.82 LUFS、真峰值 −2.15 dBTP。最终MP4音轨解码峰值 0.779301，与预定混音相关系数 0.999848，没有数值削波。自动浏览器播放静音，未进行真人试听，不能声称音效观感已通过人耳验收。

## 依赖与限制

Remotion 4.0.536、React 19.2.4、TypeScript 5.9.3和Chromium/FFmpeg沿用现有安装，没有新增npm依赖。Python声音制作使用既有NumPy/SciPy，字体子集使用既有fontTools。

可编辑工程包含原始PNG、全部Remotion源码、字体、音轨与生成/检查脚本。不是可旋转至任意视角的三维模型工程。技术检查不能认证“最惊艳”或电影级审美；以实际成片供用户判断。其他系统上的完整依赖安装和渲染未验证。
